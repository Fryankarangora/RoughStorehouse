# RoughStorehouse

RoughStorehouse is a real-time, distributed data processing platform that automates data management, scaling, and monitoring as a service.

With RoughStorehouse, you get a lightweight tool that stays out of your way.

**What you get**

- RoughStorehouse is a real-time, distributed
- data processing platform that automates
- data management, scaling, and monitoring

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/RoughStorehouse.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

RoughStorehouse is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
